Public support information for Midnight Chess Club. This repository contains public documentation only; it does not contain the game source or private support reports.

Please email support. Do not publish save files, profile credentials, room codes, personal information or diagnostic reports in a public issue.

The policy describes released behavior. New features are documented when available. GitHub Pages also hosts [Support](https://vegasq.github.io/midnight-chess-club-support/) and [Privacy](https://vegasq.github.io/midnight-chess-club-support/privacy/), verified over HTTPS. Pages uses the main branch and repository root.

## Delete a profile

In version 0.19, open Settings > Delete profile & server data, then confirm the named profile. Remove from this device clears only the local save. Delete profile & server data also requests authenticated erasure from the hosted service. Offline requests remain pending; keep the app and stored data until confirmation. Device/platform unlocks and historical backups/logs have separate scope; see the privacy policy. Earlier installed builds may not provide this control.
